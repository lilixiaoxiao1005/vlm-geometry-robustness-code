# Public data

No dataset files are bundled. Download Mendeley Data Version 1, DOI https://doi.org/10.17632/m7jtfvtwfv.1, separately and pass its directory with `--input-dir`. The data licence is CC BY 4.0, separate from the MIT project code licence. Figure 8 and Supplementary Figure S1 require an additional author-controlled aggregate input absent from Version 1. Source-level data, benchmark images, labels and model weights are outside this package.
